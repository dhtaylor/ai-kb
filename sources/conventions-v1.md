The contract this KB's conventions descend from. It supplied the domain layout, INDEX router and descent
rule, provenance model, granularity guidance and naming rules that survive into v2 intact.

(name-field-global → root-scoped by filename), contradictions (annotate-in-place → `CONFLICTED` and refused
at retrieval), and currency granularity (file-level `verified:` → section-level stamps, the file carrying
only the floor).

carried: `memory/memory-system-architecture.md`, the `data-dictionary/` sub-index reference
implementation, and the `knowledge/scripts/check-links` script.
